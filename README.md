# 🌾 Agricultural Pest Classifier

A machine learning project for classifying agricultural pests from images using deep learning techniques.  
The goal of this project is to help in early detection of crop pests to support farmers and improve agricultural productivity.

---

## 📌 Project Overview
Agricultural pests can cause significant damage to crops if not detected early.  
This project uses a trained deep learning model to classify images of agricultural pests into their respective categories.

The system supports:
- Image-based pest classification
- Running inference using a Python script
- Experimentation and training through Jupyter Notebooks

---

## 🧠 Model Details
- Model type: Convolutional Neural Network (CNN)
- Framework: TensorFlow / Keras
- Trained model file: `pest_model.h5`
